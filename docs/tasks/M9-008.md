# Task M9-008: Leaderboard UI

**Milestone:** M9 Notifications & Analytics
**Dependencies:** M9-005

## Goal
Build the leaderboard screen with a friends/global toggle and a ranked list displaying avatar, name, level, and points for each user.

## Why This Task Exists
Users need a visual interface to see their ranking among friends and globally. The leaderboard UI drives competitive engagement and motivates continued learning.

## Source Docs
- M9-005 (Leaderboards API)
- UI/UX design specs

## Non-Goals
- No filtering by category or time range
- No weekly/monthly views

## Files Expected
- `android/app/src/main/kotlin/.../leaderboard/LeaderboardScreen.kt`
- `android/app/src/main/kotlin/.../leaderboard/LeaderboardViewModel.kt`
- `android/app/src/main/kotlin/.../leaderboard/LeaderboardItem.kt`

## Acceptance Criteria
- [ ] Leaderboard screen has friends/global toggle
- [ ] Ranked list shows avatar, name, level, and points
- [ ] Current user is highlighted in the list
- [ ] Toggle switches between friends and global rankings
- [ ] Loading and empty states handled

## Tests Required
- ViewModel state tests for leaderboard loading
- ViewModel state tests for friends/global toggle switching
- ViewModel correctly highlights current user
- ViewModel handles empty friends list
