# Task M1-001: Define shared domain models (enums, core entities)

**Milestone:** M1 Foundation
**Dependencies:** None

## Goal
Create all shared Kotlin enum classes and core data classes in the `shared/` module matching docs/04-domain-model.md.

## Why This Task Exists
Every layer of the application (backend, frontend, shared networking) depends on a common vocabulary of domain types. Defining these models first ensures all subsequent tasks can import stable, well-typed entities without circular dependencies or ad-hoc redefinition.

## Source Docs
- docs/04-domain-model.md

## Non-Goals
- No DTOs or API request/response contracts
- No database layer or table mappings
- No validation or business logic
