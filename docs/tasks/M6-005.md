# Task M6-005: Feed UI with switching bar

**Milestone:** M6 Feeds
**Dependencies:** M1-006, M6-003, M4-007

## Goal
Build the home screen with a transparent top tab bar for switching between For You and Deep Dive feeds. The feed displays as a vertical scrolling reel and integrates reel playback from M4-007.

## Why This Task Exists
The feed is the primary user-facing screen of the app. Users need an intuitive way to browse content and switch between their personalized For You feed and the exploratory Deep Dive feed.

## Source Docs
- M1-006 (Navigation setup)
- M6-003 (Feed API endpoints)
- M4-007 (Reel playback)
- UI/UX design specs

## Non-Goals
- No search or explore screen
- No pull-to-refresh (unless trivial to add)

## Files Expected
- `android/app/src/main/kotlin/.../feed/FeedScreen.kt`
- `android/app/src/main/kotlin/.../feed/FeedViewModel.kt`
- `android/app/src/main/kotlin/.../feed/FeedTabBar.kt`
- `android/app/src/main/kotlin/.../feed/FeedReelItem.kt`

## Acceptance Criteria
- [ ] Home screen displays a vertical scrolling reel feed
- [ ] Transparent top tab bar with For You and Deep Dive tabs
- [ ] Switching tabs loads the corresponding feed
- [ ] Integrates reel playback component from M4-007
- [ ] Cursor-based pagination loads more content on scroll
- [ ] Loading and empty states are handled

## Tests Required
- ViewModel tests for feed loading state management
- ViewModel tests for tab switching triggers correct feed fetch
- Pagination triggers on scroll near end of list
- Empty feed state rendered correctly
