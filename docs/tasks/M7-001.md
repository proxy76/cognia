# Task M7-001: Follow system

**Milestone:** M7 Social
**Dependencies:** M2-005

## Goal
Implement the follow system with POST/DELETE /users/{id}/follow endpoints, GET followers/following lists, and the underlying Follow model and repository.

## Why This Task Exists
Following creators is the foundation of the social graph. It enables users to discover content from creators they care about and provides the basis for social features like friend-only leaderboards.

## Source Docs
- M2-005 (User profiles)
- Social feature specs

## Non-Goals
- No friend system (that is M7-002)
- No notifications on follow (that is M9)

## Files Expected
- `server/src/main/kotlin/.../social/Follow.kt`
- `server/src/main/kotlin/.../social/FollowRepository.kt`
- `server/src/main/kotlin/.../social/FollowService.kt`
- `server/src/main/kotlin/.../social/FollowController.kt`
- Database migration for follows table

## Acceptance Criteria
- [ ] POST /users/{id}/follow creates a follow relationship
- [ ] DELETE /users/{id}/follow removes a follow relationship
- [ ] GET /users/{id}/followers returns paginated follower list
- [ ] GET /users/{id}/following returns paginated following list
- [ ] Follower/following counts available on user profile
- [ ] Cannot follow yourself

## Tests Required
- Follow a user successfully
- Unfollow a user successfully
- Duplicate follow is handled gracefully (idempotent or error)
- Follower count is accurate after follow/unfollow
- Cannot follow yourself
