# Task M4-007: Reel Playback UI

**Milestone:** M4 Content & Playback
**Dependencies:** M4-005

## Goal
Build a full-screen vertical video player with overlay UI (creator info, title, quiz button) and swipe navigation between videos.

## Why This Task Exists
The reel-style playback experience is the primary way users consume content. The vertical video player with swipe navigation mirrors familiar short-form video patterns and is central to the app experience.

## Source Docs
- Video serving API from M4-005
- UI/UX wireframes for reel player
- Video entity model

## Non-Goals
- No feed integration — this task builds only the player component itself
- No feed algorithm or recommendation logic
- No comments or social features

## Files Expected
- Reel player screen composable/view
- Reel player ViewModel
- Video player component (ExoPlayer or platform equivalent)
- Overlay UI components (creator info, title, quiz button)
- Swipe gesture handler for navigation

## Acceptance Criteria
- [ ] Full-screen vertical video playback
- [ ] Overlay shows creator name, video title, and quiz button (if quiz exists)
- [ ] Swipe up/down navigates to next/previous video
- [ ] Video auto-plays on display
- [ ] Pause/resume on tap
- [ ] Loading indicator while buffering
- [ ] Error state for failed video load

## Tests Required
- ViewModel state tests for playback states (playing, paused, buffering, error)
- ViewModel state tests for overlay visibility
- ViewModel state tests for swipe navigation (next/previous)
- ViewModel state tests for tap to pause/resume
