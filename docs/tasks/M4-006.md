# Task M4-006: Creator Upload UI

**Milestone:** M4 Content & Playback
**Dependencies:** M1-006, M4-002

## Goal
Build the upload screen with file picker, metadata form (title, description, category, difficulty for licensed creators), and submit/publish buttons.

## Why This Task Exists
Creators need a mobile interface to upload videos and fill in metadata. The UI must adapt based on creator type — licensed creators see additional fields (difficulty) and can publish directly.

## Source Docs
- Upload API from M4-002
- Video metadata API from M4-004
- Creator role definitions
- UI/UX wireframes

## Non-Goals
- No quiz creation UI — that is a separate task (M5-008)
- No video processing status display
- No draft management screen

## Files Expected
- Upload screen composable/view
- Upload ViewModel
- File picker integration
- Metadata form components
- Category selector component
- Difficulty selector component (licensed creators only)

## Acceptance Criteria
- [ ] File picker allows selecting video files from device
- [ ] Metadata form includes title, description, category fields
- [ ] Licensed creators see difficulty selector
- [ ] Submit button triggers upload and metadata save
- [ ] Publish button available for licensed creators
- [ ] Loading state shown during upload
- [ ] Error handling for upload failures
- [ ] Form validation (required fields, character limits)

## Tests Required
- ViewModel state tests for file selection
- ViewModel state tests for form validation
- ViewModel state tests for upload progress
- ViewModel state tests for submit vs publish button visibility based on role
- Error state handling
