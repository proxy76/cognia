# Task M5-001: Quiz Domain Models

**Milestone:** M5 Quiz & Progression
**Dependencies:** M1-001, M1-003

## Goal
Create Quiz, QuizQuestion, and QuizOption tables and repositories with full CRUD support.

## Why This Task Exists
Quizzes are the primary interactive learning tool attached to videos. The domain model must support multiple question types (multiple choice, true/false) with flexible options, forming the foundation for quiz creation, taking, and scoring.

## Source Docs
- Domain model documentation for Quiz, QuizQuestion, QuizOption entities
- Database schema design
- Quiz type definitions (multiple choice, true/false)

## Non-Goals
- No scoring or attempt tracking — that belongs in M5-003
- No quiz API endpoints — that's M5-002
- No UI

## Files Expected
- Quiz entity/table definition
- QuizQuestion entity/table definition
- QuizOption entity/table definition
- Repository interfaces and implementations for each entity
- Database migrations for all quiz-related tables

## Acceptance Criteria
- [ ] Quiz table with fields: id, video ID (optional), title, type, difficulty, creator ID, status, timestamps
- [ ] QuizQuestion table with fields: id, quiz ID, question text, question type, order
- [ ] QuizOption table with fields: id, question ID, option text, is correct, order
- [ ] Repositories support CRUD for quiz with nested questions and options
- [ ] Cascade delete: deleting a quiz removes its questions and options
- [ ] Quiz can exist independently or linked to a video

## Tests Required
- Create quiz with questions and options
- Read quiz with nested questions and options
- Update quiz metadata
- Delete quiz cascades to questions and options
- CRUD for individual questions within a quiz
- CRUD for individual options within a question
