# Task M7-007: Follow/unfollow UI

**Milestone:** M7 Social
**Dependencies:** M7-001, M2-008

## Goal
Build the follow button on creator profiles and the following/followers lists accessible from the profile screen.

## Why This Task Exists
Users need a visual interface to follow and unfollow creators and to browse their social connections. This is the client-side counterpart to the follow system API.

## Source Docs
- M7-001 (Follow system API)
- M2-008 (Profile UI)
- UI/UX design specs

## Non-Goals
- No friend UI (that is M7-008)

## Files Expected
- `android/app/src/main/kotlin/.../social/FollowButton.kt`
- `android/app/src/main/kotlin/.../social/FollowersScreen.kt`
- `android/app/src/main/kotlin/.../social/FollowingScreen.kt`
- `android/app/src/main/kotlin/.../social/FollowViewModel.kt`

## Acceptance Criteria
- [ ] Follow button on creator profile toggles follow/unfollow state
- [ ] Followers list accessible from profile
- [ ] Following list accessible from profile
- [ ] Follow/unfollow state updates optimistically
- [ ] Follower/following counts update on profile

## Tests Required
- ViewModel state tests for follow/unfollow toggle
- ViewModel handles API errors gracefully
- Follower/following count updates after action
