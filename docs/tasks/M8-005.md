# Task M8-005: Creator license request API

**Milestone:** M8 Moderation & Licensing
**Dependencies:** M2-005

## Goal
Implement POST /licensing/request that allows creators with 5 or more approved videos to request a creator license, and GET endpoint for moderators to view pending license requests.

## Why This Task Exists
The licensing system rewards prolific creators by upgrading their role, which grants privileges like post-publication content (skipping the pre-publication moderation queue). The 5-video threshold ensures creators have demonstrated consistent quality.

## Source Docs
- M2-005 (User roles)
- Licensing specs

## Non-Goals
- No approval or revocation logic (that is M8-006)

## Files Expected
- `server/src/main/kotlin/.../licensing/LicenseRequest.kt`
- `server/src/main/kotlin/.../licensing/LicenseRequestRepository.kt`
- `server/src/main/kotlin/.../licensing/LicenseService.kt`
- `server/src/main/kotlin/.../licensing/LicenseController.kt`
- Database migration for license_requests table

## Acceptance Criteria
- [ ] POST /licensing/request creates a license request
- [ ] Request is rejected if creator has fewer than 5 approved videos
- [ ] Duplicate pending request is prevented
- [ ] GET /licensing/requests returns pending requests (moderator only)
- [ ] Request stores creator ID, status, and timestamps

## Tests Required
- License request succeeds with 5 or more approved videos
- License request fails with fewer than 5 approved videos
- Duplicate pending request is prevented
- Moderator can list pending requests
