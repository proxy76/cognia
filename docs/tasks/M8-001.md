# Task M8-001: Moderation review queue

**Milestone:** M8 Moderation & Licensing
**Dependencies:** M4-001, M2-005

## Goal
Create the ModerationReview table, repository, and queue API (GET /moderation/queue) that returns pending reviews for both regular pre-publication and post-publication content.

## Why This Task Exists
Content moderation is essential for platform safety. A review queue gives moderators a centralized place to review submitted content before or after it goes live.

## Source Docs
- M4-001 (Content domain)
- M2-005 (User roles)
- Moderation specs

## Non-Goals
- No decision logic (approve/reject) — that is M8-002

## Files Expected
- `server/src/main/kotlin/.../moderation/ModerationReview.kt`
- `server/src/main/kotlin/.../moderation/ModerationReviewRepository.kt`
- `server/src/main/kotlin/.../moderation/ModerationService.kt`
- `server/src/main/kotlin/.../moderation/ModerationController.kt`
- Database migration for moderation_reviews table

## Acceptance Criteria
- [ ] ModerationReview table stores content reference, review type, status, timestamps
- [ ] GET /moderation/queue returns pending reviews
- [ ] Queue can be filtered by review type (pre-publication, post-publication)
- [ ] Only users with moderator role can access the queue
- [ ] Queue is sorted by submission time (oldest first)

## Tests Required
- Queue returns pending reviews
- Queue filters by review type
- Moderator role is required (non-moderator gets 403)
- Queue is ordered by submission time
