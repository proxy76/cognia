# Task M7-008: Friend request UI

**Milestone:** M7 Social
**Dependencies:** M7-002

## Goal
Build the add friend button on profiles, a friend requests screen with accept/decline actions, and a friends list screen.

## Why This Task Exists
Users need a way to send, receive, and manage friend requests through the app interface. This is the client-side counterpart to the friend request system API.

## Source Docs
- M7-002 (Friend request system API)
- UI/UX design specs

## Non-Goals
- No chat UI (that is M7-009)

## Files Expected
- `android/app/src/main/kotlin/.../social/AddFriendButton.kt`
- `android/app/src/main/kotlin/.../social/FriendRequestsScreen.kt`
- `android/app/src/main/kotlin/.../social/FriendsListScreen.kt`
- `android/app/src/main/kotlin/.../social/FriendViewModel.kt`

## Acceptance Criteria
- [ ] Add friend button on profiles sends a friend request
- [ ] Friend requests screen lists pending incoming requests
- [ ] Accept and decline actions work on pending requests
- [ ] Friends list shows accepted friends
- [ ] Button state reflects current relationship (none, pending, friends)

## Tests Required
- ViewModel state tests for sending friend request
- ViewModel state tests for accepting/declining requests
- ViewModel state tests for relationship state display
