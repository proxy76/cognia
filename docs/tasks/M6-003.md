# Task M6-003: Feed API endpoints

**Milestone:** M6 Feeds
**Dependencies:** M6-001, M6-002

## Goal
Expose GET /feeds/for-you and GET /feeds/deep-dive REST endpoints with cursor-based pagination, wiring up the feed services built in M6-001 and M6-002.

## Why This Task Exists
The mobile app needs API endpoints to fetch feed data. These endpoints provide the contract between the backend feed logic and the client UI.

## Source Docs
- M6-001 (For You feed service)
- M6-002 (Deep Dive feed service)
- API design conventions

## Non-Goals
- No behavior tracking on these endpoints (that comes in M6-004)

## Files Expected
- `server/src/main/kotlin/.../feed/FeedController.kt`
- `server/src/main/kotlin/.../feed/FeedResponseDtos.kt`

## Acceptance Criteria
- [ ] GET /feeds/for-you returns For You feed content with cursor pagination
- [ ] GET /feeds/deep-dive returns Deep Dive feed content with cursor pagination
- [ ] Both endpoints require authentication
- [ ] Cursor-based pagination with configurable page size
- [ ] Empty feed returns empty list with no errors

## Tests Required
- Both endpoints return correct feed type
- Pagination works with cursor parameter
- Empty feed handling (no content, no matched categories)
- Unauthenticated requests are rejected
