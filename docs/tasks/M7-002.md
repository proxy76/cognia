# Task M7-002: Friend request system

**Milestone:** M7 Social
**Dependencies:** M2-005

## Goal
Implement the friend request system with POST /friends/request, PUT accept/decline, GET friends list, and DELETE unfriend. The Friendship model supports PENDING, ACCEPTED, and DECLINED states.

## Why This Task Exists
Friendships are mutual relationships (unlike follows) that unlock features like friend leaderboards and friend-only content sharing. The request/accept flow ensures both parties consent to the relationship.

## Source Docs
- M2-005 (User profiles)
- Social feature specs

## Non-Goals
- No chat (that is M7-003+)
- No notifications on friend request (that is M9)

- `server/src/main/kotlin/.../social/Friendship.kt`

- Database migration for friendships table

## Acceptance Criteria
- [ ] POST /friends/request sends a friend request (state: PENDING)
- [ ] PUT /friends/request/{id}/accept transitions to ACCEPTED
- [ ] PUT /friends/request/{id}/decline transitions to DECLINED
- [ ] GET /friends returns list of accepted friends
- [ ] DELETE /friends/{id} removes the friendship (unfriend)
- [ ] Friendship is mutual (both users see each other as friends)
- [ ] Cannot send duplicate pending requests

## Tests Required
- Send friend request successfully
- Accept friend request transitions to ACCEPTED
- Decline friend request transitions to DECLINED
- Duplicate pending request is prevented
- Unfriend removes the relationship for both users
- Friendship is mutual (both users appear in each other's friends list)
