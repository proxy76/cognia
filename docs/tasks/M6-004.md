# Task M6-004: Feed behavior tracking

**Milestone:** M6 Feeds
**Dependencies:** M6-003

## Goal
Track user engagement events (view, quiz attempt) per content item. If a Deep Dive category receives repeated engagement from a user, mark that category for potential promotion into their For You feed.

## Why This Task Exists
User behavior should influence feed personalization over time. Tracking engagement on Deep Dive content allows the system to detect when a user is developing genuine interest in a new category, enabling future promotion to their For You feed.

## Source Docs
- M6-003 (Feed API endpoints)
- Feed personalization specs

## Non-Goals
- No ML-based analysis
- No real-time feed updates based on engagement (batch/async processing is fine)

## Files Expected
- `server/src/main/kotlin/.../feed/FeedEngagementService.kt`
- `server/src/main/kotlin/.../feed/FeedEngagementRepository.kt`
- `server/src/main/kotlin/.../feed/EngagementEvent.kt`
- Database migration for engagement events table

## Acceptance Criteria
- [ ] Engagement events (view, quiz attempt) are recorded per user per content
- [ ] Events include timestamp, event type, content ID, and feed source (For You vs Deep Dive)
- [ ] Repeated Deep Dive engagement in a category is detected and flagged
- [ ] Flagged categories are stored for potential For You promotion

## Tests Required
- Engagement events are stored correctly
- Repeated Deep Dive engagement in a single category is flagged
- Engagement on For You content does not trigger flagging
- Duplicate events within a short window are handled appropriately
