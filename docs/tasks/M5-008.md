# Task M5-008: Quiz Creation UI (Creator)

**Milestone:** M5 Quiz & Progression
**Dependencies:** M5-002, M4-006

## Goal
Build the quiz builder screen: select quiz type, add questions with options, mark correct answers, set metadata, and submit/publish.

## Why This Task Exists
Creators need a mobile-friendly interface to build quizzes for their content. The builder must support multiple question types and provide a clear workflow for constructing, reviewing, and publishing quizzes.

## Source Docs
- Quiz CRUD API from M5-002
- Creator upload UI patterns from M4-006
- UI/UX wireframes for quiz builder

## Non-Goals
- No video attachment UI — quiz is created standalone (video linking handled elsewhere)
- No quiz analytics or performance tracking
- No AI-assisted question generation

## Files Expected
- Quiz builder screen composable/view
- Quiz builder ViewModel
- Question editor component
- Option editor component (with correct answer marking)
- Quiz metadata form (title, type, difficulty)
- Quiz preview/review step
- Submit/publish button logic

## Acceptance Criteria
- [ ] Creator can select quiz type (multiple choice, true/false)
- [ ] Creator can add multiple questions
- [ ] Each question has editable text and configurable options
- [ ] Creator can mark correct answer(s) for each question
- [ ] Quiz metadata form: title, difficulty, category
- [ ] Preview step shows quiz as it will appear to takers
- [ ] Submit button for regular creators, publish for licensed
- [ ] Form validation (minimum questions, all questions have correct answer marked)
- [ ] Questions can be reordered and deleted

## Tests Required
- ViewModel state tests for adding questions
- ViewModel state tests for editing options
- ViewModel state tests for marking correct answers
- ViewModel state tests for form validation
- ViewModel state tests for submit vs publish based on role
- ViewModel state tests for question reorder and delete
