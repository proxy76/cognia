# Task M8-007: Web moderation dashboard

**Milestone:** M8 Moderation & Licensing
**Dependencies:** M8-001, M8-002, M8-003, M8-005

## Goal
Build a Compose for Web moderation UI with a review queue featuring tabs (videos, quizzes, reports, license requests), a review screen with approve/reject actions, report actions, and license decisions.

## Why This Task Exists
Moderators need a dedicated web-based interface to efficiently review and act on queued content, reports, and license requests. A web dashboard is more practical for moderation workflows than a mobile interface.

## Acceptance Criteria
- [ ] Dashboard has tabbed navigation for videos, quizzes, reports, and license requests
- [ ] Review queue displays pending items with relevant metadata
- [ ] Review screen supports approve and reject actions with reason input
- [ ] Report queue displays reports with dismiss, remove, and strike actions
- [ ] License requests screen shows pending requests with approve/reject
- [ ] Moderator authentication required

## Tests Required

- State tests for tab switching
- State tests for approve/reject action flow
- State tests for report action handling
