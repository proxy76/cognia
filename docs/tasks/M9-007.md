# Task M9-007: Creator analytics UI

**Milestone:** M9 Notifications & Analytics
**Dependencies:** M9-004

## Goal
Build the analytics screen showing views, quiz attempts, correct rate, and shares per video for the creator.

## Why This Task Exists
Creators need a visual dashboard to understand how their content is performing. This screen presents the analytics data from the API in an accessible format.

## Source Docs
- M9-004 (Creator analytics API)
- UI/UX design specs

## Non-Goals
- No charts or graphs
- No data export

## Files Expected
- `android/app/src/main/kotlin/.../analytics/AnalyticsScreen.kt`
- `android/app/src/main/kotlin/.../analytics/AnalyticsViewModel.kt`
- `android/app/src/main/kotlin/.../analytics/VideoAnalyticsItem.kt`

## Acceptance Criteria
- [ ] Analytics screen lists the creator's videos with stats
- [ ] Each video shows view count, quiz attempts, correct rate, and shares
- [ ] Loading and empty states handled
- [ ] Only accessible to creators

## Tests Required
- ViewModel state tests for analytics loading
- ViewModel state tests for empty state
- ViewModel correctly maps API response to UI state
