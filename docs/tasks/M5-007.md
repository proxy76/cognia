# Task M5-007: Quiz-Taking UI

**Milestone:** M5 Quiz & Progression
**Dependencies:** M1-006, M5-002

## Goal
Build the quiz-taking screen with question display, answer selection (multiple choice buttons or true/false toggle), immediate feedback per question, and a results screen.

## Why This Task Exists
The quiz-taking experience is a core interaction loop. Users need a clean, intuitive interface to answer questions, see immediate feedback on correctness, and view their final results.

## Source Docs
- Quiz API from M5-002
- Quiz attempt API from M5-003
- UI/UX wireframes for quiz screens

## Non-Goals
- No quiz creation UI — that's M5-008
- No quiz listing or discovery (feed task)

## Files Expected
- Quiz-taking screen composable/view
- Quiz-taking ViewModel
- Question display component
- Answer selection components (MC buttons, T/F toggle)
- Feedback display component (correct/incorrect)
- Results screen composable/view
- Results ViewModel or shared state

## Acceptance Criteria
- [ ] Questions displayed one at a time with progress indicator
- [ ] Multiple choice questions show selectable option buttons
- [ ] True/false questions show toggle or two-button selection
- [ ] Immediate feedback shown after answer selection (correct/incorrect)
- [ ] Results screen shows score, points earned, and per-question summary
- [ ] Navigation: next question after feedback, results after last question
- [ ] Loading state while fetching quiz data
- [ ] Error handling for API failures

## Tests Required
- ViewModel state tests for question loading
- ViewModel state tests for answer selection
- ViewModel state tests for feedback display
- ViewModel state tests for results computation
- ViewModel state tests for navigation between questions
- Error state handling
