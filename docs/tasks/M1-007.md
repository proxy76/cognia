# Task M1-007: Define DTO serialization contracts

**Milestone:** M1 Foundation
**Dependencies:** M1-001

## Goal
Create all request and response DTO (Data Transfer Object) classes with kotlinx.serialization annotations, matching the contracts defined in docs/06-api-contracts.md.

## Why This Task Exists
DTOs form the explicit contract between client and server. Defining them upfront in the shared module ensures both sides agree on the shape of every API request and response before any endpoint is implemented, preventing integration mismatches.

## Source Docs
- docs/06-api-contracts.md
- docs/04-domain-model.md (for referenced types)

## Non-Goals
- No API route implementations
- No validation logic (validation is a concern of the service layer)
- No mapping functions between DTOs and domain models

## Acceptance Criteria

- [ ] DTOs reference shared enums from M1-001 where applicable
