# Task M9-004: Basic creator analytics API

**Milestone:** M9 Notifications & Analytics
**Dependencies:** M4-001, M5-001

## Goal
Implement GET /analytics/me that aggregates views, quiz attempts, correct rate, and shares per video for the authenticated creator.

## Why This Task Exists
Creators need insight into how their content is performing. Basic analytics give creators feedback on engagement and quiz effectiveness, motivating continued content creation.

## Source Docs
- M4-001 (Content domain)
- M5-001 (Quiz domain)
- Analytics specs

## Non-Goals
- No advanced analytics or dashboards
- No time-series data or historical trends

## Files Expected
- `server/src/main/kotlin/.../analytics/AnalyticsService.kt`
- `server/src/main/kotlin/.../analytics/AnalyticsController.kt`
- `server/src/main/kotlin/.../analytics/AnalyticsDtos.kt`

## Acceptance Criteria
- [ ] GET /analytics/me returns aggregated stats per video
- [ ] Stats include: view count, quiz attempt count, correct rate, share count
- [ ] Only the creator's own content is included
- [ ] Empty state (no content) returns empty analytics
- [ ] Authentication required, creator-only access

## Tests Required
- Correct aggregation of views, attempts, correct rate, shares
- Creator-only access enforced
- Empty state returns empty analytics without error
- Stats are per-video, not global totals only
