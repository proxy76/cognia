# Task M5-004: Difficulty-Based Points Calculation

**Milestone:** M5 Quiz & Progression
**Dependencies:** M5-003

## Goal
Apply difficulty multiplier to quiz points (easy=10, medium=20, hard=30 per correct answer — pending confirmation). Update the user's total points after each quiz attempt.

## Why This Task Exists
Difficulty-based scoring incentivizes users to attempt harder quizzes, rewarding deeper learning. Aggregating total points on the user profile enables the levels and badges systems.

## Source Docs
- Scoring logic from M5-003
- Difficulty definitions
- Points system design

## Non-Goals
- No levels system — that's M5-005
- No badges — that's M5-006
- No leaderboard

## Files Expected
- Difficulty multiplier configuration/constants
- Points calculation service (extends or wraps scoring from M5-003)
- User points update logic
- User total points field (migration if not already present)

## Acceptance Criteria
- [ ] Easy quiz correct answer awards 10 points
- [ ] Medium quiz correct answer awards 20 points
- [ ] Hard quiz correct answer awards 30 points
- [ ] Points multiplier values are configurable
- [ ] User total points updated after each attempt
- [ ] Quizzes without difficulty set use base points (no multiplier)

## Tests Required
- Easy difficulty awards correct point value
- Medium difficulty awards correct point value
- Hard difficulty awards correct point value
- No-difficulty quiz uses base points
- User total points updated correctly after attempt
- Multiple attempts accumulate points
