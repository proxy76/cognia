# Task M6-002: Deep Dive feed generation logic

**Milestone:** M6 Feeds
**Dependencies:** M4-001

## Goal
Build a feed service that generates a Deep Dive feed from categories the user has NOT selected. This exposes users to content outside their comfort zone, encouraging broader learning.

## Why This Task Exists
The Deep Dive feed complements the For You feed by surfacing content from categories the user hasn't chosen, enabling discovery of new topics and broadening the user's knowledge base.

## Source Docs
- M4-001 (Content domain and publishing)
- Feed design specs

## Non-Goals
- No behavior-based promotion of Deep Dive categories into For You feed (that comes in M6-004)

## Files Expected
- `server/src/main/kotlin/.../feed/DeepDiveFeedService.kt`
- Updates to `FeedRepository.kt` if shared queries are needed

## Acceptance Criteria
- [ ] Feed service returns content from categories the user has NOT selected
- [ ] Only published content is included
- [ ] Content is sorted by recency
- [ ] Pagination support via cursor-based pagination
- [ ] Empty feed handled gracefully

## Tests Required
- Feed returns content outside user's selected categories
- Feed excludes unpublished content
- Pagination works correctly
- User with all categories selected gets empty Deep Dive feed
