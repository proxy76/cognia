# Task M5-006: Badges System

**Milestone:** M5 Quiz & Progression
**Dependencies:** M5-005

## Goal
Define badge types, implement badge awarding logic for key achievements (first quiz completed, 10 quizzes completed, first video watched, etc.), and store awarded badges per user.

## Why This Task Exists
Badges provide recognition for specific achievements beyond the linear levels system. They encourage exploration of different platform features and reward milestone accomplishments.

## Source Docs
- Gamification design documentation
- Badge definitions and criteria
- User progression model

## Non-Goals
- No badge display UI — backend only
- No badge notifications UI
- No social sharing of badges

## Files Expected
- Badge definition entity/table
- User badge (awarded) entity/table
- Badge criteria/rules engine
- Badge awarding service
- Badge repository
- Database migrations for badge tables
- Seed data for badge definitions

## Acceptance Criteria
- [ ] Badge definitions stored with name, description, icon, criteria type
- [ ] Badge awarding logic checks criteria after relevant events (quiz complete, video watched, etc.)
- [ ] Badges awarded: first quiz, 10 quizzes, 50 quizzes, first video, streak badges, etc.
- [ ] No duplicate badge awards — each badge awarded at most once per user
- [ ] User's badge list retrievable via API
- [ ] Badge criteria are extensible for future badge types

## Tests Required
- Badge awarded when criteria met (e.g., first quiz completed)
- Duplicate badge not awarded on repeated triggers
- Multiple badges can be awarded from single event
- Badge list retrieval returns all user badges
- Badge not awarded when criteria not met
- Badge definitions seeded correctly
