# Task M2-004: OAuth endpoints (Google, Apple)

**Milestone:** M2 Auth & Profiles
**Dependencies:** M2-003

## Goal
Implement POST /auth/oauth/google and POST /auth/oauth/apple endpoints. Each endpoint validates the external provider's token, finds or creates a user in the database, and issues a JWT token pair via the TokenService from M2-003.

## Why This Task Exists
OAuth login reduces friction for users who prefer not to create yet another email/password account. Supporting Google and Apple covers the vast majority of mobile users and is expected for a modern consumer app.

## Source Docs
- docs/06-api-contracts.md (POST /auth/oauth/google, POST /auth/oauth/apple)

## Non-Goals
- No OAuth token refresh from the external provider (Google/Apple)
- No UI for OAuth buttons (covered in later UI tasks)
- No linking multiple OAuth providers to a single account

## Files Expected
- server/src/main/kotlin/com/cognia/app/routes/OAuthRoutes.kt
- server/src/main/kotlin/com/cognia/app/service/OAuthService.kt
- server/src/main/kotlin/com/cognia/app/service/GoogleTokenVerifier.kt
- server/src/main/kotlin/com/cognia/app/service/AppleTokenVerifier.kt

## Acceptance Criteria
- [ ] POST /api/v1/auth/oauth/google accepts OAuthGoogleRequest with idToken field
- [ ] Google endpoint validates the ID token against Google's public keys
- [ ] POST /api/v1/auth/oauth/apple accepts OAuthAppleRequest with identityToken and authorizationCode fields
- [ ] Apple endpoint validates the identity token against Apple's public keys
- [ ] If user with matching email exists, log them in and return AuthResponse
- [ ] If user does not exist, create a new User record and return AuthResponse
- [ ] AuthResponse includes JWT access token and refresh token from TokenService
- [ ] Invalid or expired provider tokens return 401
- [ ] Token verifiers are injectable/mockable for testing

## Tests Required
- Google auth success: valid token for new user creates account and returns AuthResponse
- Google auth existing user: valid token for known email returns AuthResponse without creating duplicate
- Apple auth success: valid token for new user creates account and returns AuthResponse
- Apple auth existing user: valid token for known email returns AuthResponse
- Invalid Google token: returns 401
- Invalid Apple token: returns 401
