# Task M1-006: Set up Compose navigation shell

**Milestone:** M1 Foundation
**Dependencies:** M1-005

## Goal
Set up Compose Navigation with a bottom navigation bar containing five tabs (Home, Search, Create, Chat, Profile) and placeholder screens for each tab.

## Why This Task Exists
The navigation shell is the structural skeleton of the entire client-side UI. Having it in place early means feature screens can be dropped into the correct navigation slots without reworking the app's navigation graph later.

## Source Docs
- docs/05-ui-ux-spec.md
- docs/03-architecture.md

## Non-Goals
- No actual screen implementations (only placeholder composables)
- No state management or ViewModel wiring
- No theming or styling beyond basic Material defaults

## Files Expected
- composeApp/src/commonMain/kotlin/com/cognia/app/navigation/AppNavGraph.kt
- composeApp/src/commonMain/kotlin/com/cognia/app/navigation/BottomNavBar.kt

- composeApp/src/commonMain/kotlin/com/cognia/app/ui/screens/HomeScreen.kt (placeholder)
- composeApp/src/commonMain/kotlin/com/cognia/app/ui/screens/SearchScreen.kt (placeholder)
- composeApp/src/commonMain/kotlin/com/cognia/app/ui/screens/CreateScreen.kt (placeholder)

## Acceptance Criteria
- [ ] Bottom navigation bar renders with five tabs: Home, Search, Create, Chat, Profile
- [ ] Tapping each tab navigates to its corresponding placeholder screen
- [ ] Each placeholder screen displays its name (e.g., "Home Screen")
- [ ] Navigation state is preserved when switching tabs (back stack per tab)
- [ ] The app compiles and runs on at least one target (Android or Desktop)

## Tests Required
