# Task M6-007: Search UI

**Milestone:** M6 Feeds
**Dependencies:** M6-006, M1-006

## Goal

Build the search screen UI with search bar, recent searches display, live results grouped by type (categories, creators, videos, quizzes), and filter tabs.

## Why This Task Exists

Search is confirmed as MVP-required. The search UI is the primary way users discover content beyond the feed.

## Source Docs

- `docs/08-ui-flows.md` (Search Flow)
- `docs/06-api-contracts.md` (Search section)

## Non-Goals

- No search suggestions/autocomplete
- No trending searches
- No offline search

## Files Expected

- `composeApp/src/commonMain/kotlin/com/cognia/app/ui/screens/search/SearchScreen.kt`
- `composeApp/src/commonMain/kotlin/com/cognia/app/ui/screens/search/SearchViewModel.kt`
- `composeApp/src/commonMain/kotlin/com/cognia/app/ui/screens/search/SearchResultItem.kt`
- Update navigation to include Search tab

## Acceptance Criteria

- [ ] Search bar with text input at top of screen
- [ ] Recent searches shown before typing (with clear all option)
- [ ] Tap recent search executes that query
- [ ] Results grouped by type: categories (chips), creators (horizontal scroll), videos and quizzes (vertical list)
- [ ] Filter tabs (All, Videos, Quizzes, Creators, Categories) above results
- [ ] Tap result navigates to correct destination (reel, quiz, profile, category)
- [ ] Loading and empty states handled

## Tests Required

- ViewModel state tests for loading, results, empty, error states
- Filter tab switching updates results
- Recent search display and clear
