# Task M7-003: Chat domain

**Milestone:** M7 Social
**Dependencies:** M2-005, M1-003

## Goal
Create the ChatConversation and ChatMessage tables, repositories, and conversation lookup/creation logic. This is the domain layer for the chat feature without any API or transport layer.

## Why This Task Exists
The chat domain provides the data foundation for direct messaging between users. Separating the domain from the API layer allows the REST and WebSocket transports to share the same business logic.

## Source Docs
- M2-005 (User profiles)
- M1-003 (Database setup)
- Chat feature specs

## Non-Goals
- No API endpoints (that is M7-004)
- No WebSocket transport (that is M7-005)

## Files Expected
- `server/src/main/kotlin/.../chat/ChatConversation.kt`
- `server/src/main/kotlin/.../chat/ChatMessage.kt`
- `server/src/main/kotlin/.../chat/ChatRepository.kt`
- `server/src/main/kotlin/.../chat/ChatService.kt`
- Database migration for chat tables

## Acceptance Criteria
- [ ] ChatConversation table stores participant pairs
- [ ] ChatMessage table stores messages with sender, conversation, timestamp, type
- [ ] Conversation lookup finds existing conversation between two users
- [ ] Conversation creation prevents duplicates for the same participant pair
- [ ] Messages retrievable in chronological order per conversation

## Tests Required
- Create a conversation between two users
- Prevent duplicate conversations for the same pair
- Store a message in a conversation
- Retrieve messages ordered by timestamp
- Conversation lookup returns existing conversation
