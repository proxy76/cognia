# Task M7-004: Chat REST API

**Milestone:** M7 Social
**Dependencies:** M7-003

## Goal
Expose REST endpoints for chat: GET /chat/conversations, GET /chat/conversations/{id}/messages, and POST messages (text type only).

## Why This Task Exists
The REST API provides the baseline chat functionality for listing conversations, loading message history, and sending messages. This works alongside the WebSocket layer for realtime delivery.

## Source Docs
- M7-003 (Chat domain)
- API design conventions

## Non-Goals
- No shared post message type (that is M7-006)
- No WebSocket transport (that is M7-005)

## Files Expected
- `server/src/main/kotlin/.../chat/ChatController.kt`
- `server/src/main/kotlin/.../chat/ChatDtos.kt`

## Acceptance Criteria
- [ ] GET /chat/conversations returns user's conversations sorted by last message time
- [ ] GET /chat/conversations/{id}/messages returns paginated messages
- [ ] POST /chat/conversations/{id}/messages sends a text message
- [ ] All endpoints require authentication
- [ ] Users can only access their own conversations

## Tests Required
- List conversations sorted by last message timestamp
- Paginated message retrieval
- Send a text message successfully
- Cannot access another user's conversation
- Unauthenticated requests rejected
