# Task M7-005: Chat WebSocket for realtime delivery

**Milestone:** M7 Social
**Dependencies:** M7-003

## Goal
Implement a WebSocket endpoint at /chat/ws that authenticates the connection and pushes new messages to the recipient in real time.

## Why This Task Exists
Real-time message delivery is essential for a chat experience. The WebSocket connection allows the server to push new messages to connected clients immediately without polling.

## Source Docs
- M7-003 (Chat domain)
- WebSocket design specs

## Non-Goals
- No typing indicators
- No read receipts
- No offline message queue

## Files Expected
- `server/src/main/kotlin/.../chat/ChatWebSocketHandler.kt`
- `server/src/main/kotlin/.../chat/ChatWebSocketConfig.kt`
- `server/src/main/kotlin/.../chat/WebSocketSessionManager.kt`

## Acceptance Criteria
- [ ] WebSocket endpoint at /chat/ws accepts authenticated connections
- [ ] Unauthenticated connection attempts are rejected
- [ ] When a message is sent, recipient receives it via WebSocket if connected
- [ ] Messages are delivered with full message payload (sender, content, timestamp)
- [ ] Disconnection is handled gracefully

## Tests Required
- Authenticated connection is accepted
- Unauthenticated connection is rejected
- Message is delivered to connected recipient in real time
- Message to disconnected user does not cause errors
