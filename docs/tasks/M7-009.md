# Task M7-009: Chat UI

**Milestone:** M7 Social
**Dependencies:** M7-004, M7-005

## Goal
Build the conversations list screen, individual chat screen with messages and text input, shared post rendering, and realtime updates via WebSocket.

## Why This Task Exists
Users need a complete chat interface to communicate with friends and share content. This is the client-side implementation that ties together the REST API for history and WebSocket for realtime delivery.

## Source Docs
- M7-004 (Chat REST API)
- M7-005 (Chat WebSocket)
- UI/UX design specs

## Non-Goals
- No image or voice messages
- No message editing or deletion

## Files Expected
- `android/app/src/main/kotlin/.../chat/ConversationsScreen.kt`
- `android/app/src/main/kotlin/.../chat/ChatScreen.kt`
- `android/app/src/main/kotlin/.../chat/ChatViewModel.kt`
- `android/app/src/main/kotlin/.../chat/SharedPostMessageItem.kt`
- `android/app/src/main/kotlin/.../chat/ChatWebSocketClient.kt`

## Acceptance Criteria
- [ ] Conversations list shows all conversations sorted by last message
- [ ] Chat screen displays messages in chronological order
- [ ] Text input allows sending messages
- [ ] Shared post messages render with content preview
- [ ] Realtime updates via WebSocket show new messages without refresh
- [ ] Loading and empty states handled

## Tests Required
- ViewModel state tests for conversation list loading
- ViewModel state tests for message sending
- ViewModel state tests for receiving realtime messages
- Shared post message rendering with content metadata
