# Task M8-006: License approval and revocation logic

**Milestone:** M8 Moderation & Licensing
**Dependencies:** M8-005, M8-002

## Goal
Implement POST /licensing/requests/{id}/decide for moderators to approve or reject license requests. On approval, upgrade the user's role to LICENSED_CREATOR. On accumulating 3 rejected licensed videos, automatically revoke the license and revert the user to REGULAR_CREATOR.

## Why This Task Exists
The license lifecycle needs both a grant path (moderator approval) and a revocation path (quality enforcement). Auto-revocation after 3 rejections ensures licensed creators maintain content quality standards.

## Source Docs
- M8-005 (Creator license request API)
- M8-002 (Moderation decision API and rejection tracking)
- Licensing specs

## Non-Goals
- No manual revocation UI beyond the moderator decision endpoint

## Files Expected
- Updates to `LicenseService.kt`
- Updates to `LicenseController.kt`
- `server/src/main/kotlin/.../licensing/LicenseRevocationService.kt`

## Acceptance Criteria
- [ ] POST /licensing/requests/{id}/decide with approve upgrades user role to LICENSED_CREATOR
- [ ] POST /licensing/requests/{id}/decide with reject includes a reason
- [ ] When a licensed creator accumulates 3 rejected videos, license is auto-revoked
- [ ] Auto-revocation changes user role back to REGULAR_CREATOR
- [ ] Only moderators can make license decisions

## Tests Required
- Approval upgrades user role to LICENSED_CREATOR
- Rejection includes a reason and does not change role
- Auto-revocation after 3 rejected licensed videos
- Role downgrade to REGULAR_CREATOR is confirmed after revocation
- Non-moderator cannot make license decisions
