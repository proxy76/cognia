# Task M8-003: Content report system

**Milestone:** M8 Moderation & Licensing
**Dependencies:** M8-001

## Goal
Implement content reporting: POST report (any authenticated user), GET /moderation/reports (moderator), POST /moderation/reports/{id}/review with actions: dismiss, remove content, or issue strike.

## Why This Task Exists
Users need the ability to report inappropriate content, and moderators need a queue to review and act on those reports. This is a critical trust and safety feature.

## Source Docs
- M8-001 (Moderation review queue)
- Content report specs

## Non-Goals
- No automated flagging or content scanning

## Files Expected
- `server/src/main/kotlin/.../moderation/ContentReport.kt`
- `server/src/main/kotlin/.../moderation/ContentReportRepository.kt`
- Updates to `ModerationService.kt`
- Updates to `ModerationController.kt`
- Database migration for content_reports table

## Acceptance Criteria
- [ ] POST /reports creates a report from any authenticated user
- [ ] Report includes content reference, reason, and reporter
- [ ] GET /moderation/reports returns pending reports (moderator only)
- [ ] POST /moderation/reports/{id}/review supports dismiss, remove content, and issue strike
- [ ] Duplicate reports from same user on same content are prevented

## Tests Required
- Report created successfully
- Report queue lists pending reports for moderator
- Dismiss action closes the report
- Remove content action deletes the reported content
- Report by 3 different users on same content scenario
- Duplicate report from same user is prevented
