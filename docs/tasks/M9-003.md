# Task M9-003: Notification WebSocket delivery

**Milestone:** M9 Notifications & Analytics
**Dependencies:** M9-001

## Goal
Implement a WebSocket endpoint at /notifications/ws that pushes new notifications to connected users in realtime.

## Why This Task Exists
Realtime notification delivery ensures users are immediately aware of important events without needing to poll. This improves responsiveness and engagement.

## Source Docs
- M9-001 (Notification creation and storage)
- WebSocket design specs

## Non-Goals
- No offline queue for missed notifications
- No push notifications to device (OS-level)

## Files Expected
- `server/src/main/kotlin/.../notification/NotificationWebSocketHandler.kt`
- `server/src/main/kotlin/.../notification/NotificationWebSocketConfig.kt`

## Acceptance Criteria
- [ ] WebSocket endpoint at /notifications/ws accepts authenticated connections
- [ ] New notifications are pushed to connected users immediately
- [ ] Unauthenticated connections are rejected
- [ ] Disconnection handled gracefully

## Tests Required
- Notification pushed to connected user in realtime
- No push to disconnected user (no error)
- Unauthenticated connection rejected
- Multiple simultaneous connections for same user handled
