# Task M8-002: Moderation decision API

**Milestone:** M8 Moderation & Licensing
**Dependencies:** M8-001

## Goal
Implement POST /moderation/reviews/{id}/decide to approve or reject content. On approve, transition content to PUBLISHED or APPROVED. On reject, transition to REJECTED or DELETED (for post-publication). Track licensed creator rejection count for potential license revocation.

## Why This Task Exists
Moderators need the ability to make decisions on queued content. The decision logic must handle different content lifecycle states and track rejections for licensed creators to support the license revocation flow.

## Source Docs
- M8-001 (Moderation review queue)
- Content lifecycle specs
- Licensing specs

## Non-Goals
- No strike logic (that is M8-004)
- No license revocation (that is M8-006)

## Files Expected
- Updates to `ModerationService.kt`
- Updates to `ModerationController.kt`
- `server/src/main/kotlin/.../moderation/ModerationDecisionDto.kt`

## Acceptance Criteria
- [ ] POST /moderation/reviews/{id}/decide accepts approve or reject with optional reason
- [ ] Approve transitions content to PUBLISHED (pre-pub) or APPROVED (post-pub)
- [ ] Reject transitions content to REJECTED (pre-pub) or DELETED (post-pub)
- [ ] Licensed creator rejection count is incremented on reject
- [ ] Only moderators can make decisions
- [ ] Decision is recorded with moderator ID, timestamp, and reason

## Tests Required
- Approve publishes pre-publication content
- Approve marks post-publication content as approved
- Reject transitions pre-publication content to REJECTED
- Post-publication reject deletes content
- Licensed creator rejection count is tracked and incremented
