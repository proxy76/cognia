# Task M4-003: Video Processing Pipeline

**Milestone:** M4 Content & Playback
**Dependencies:** M4-002

## Goal
Implement an async video processing service that transcodes uploaded videos via FFmpeg and generates thumbnails. Update the video record with processed file URLs upon completion.

## Why This Task Exists
Raw uploaded videos need to be transcoded to a standard format for consistent playback across devices. Thumbnails are needed for video listings and previews. Processing must be async to avoid blocking the upload flow.

## Source Docs
- Video entity from M4-001
- Upload flow from M4-002
- FFmpeg transcoding requirements

## Non-Goals
- No video streaming or serving (that's M4-005)
- No CDN integration
- No adaptive bitrate encoding

## Files Expected
- Video processing service interface and implementation
- FFmpeg wrapper/integration
- Thumbnail generation logic
- Async job/task execution mechanism
- Processing status update logic

## Acceptance Criteria
- [ ] Processing runs asynchronously after upload
- [ ] FFmpeg transcodes video to target format/codec
- [ ] Thumbnail generated from video frame
- [ ] Video record updated with processed video URL and thumbnail URL
- [ ] Video status updated to reflect processing completion
- [ ] Failed processing is handled gracefully (status set to error, logged)

## Tests Required
- Processing updates video record with processed URLs
- Thumbnail is generated and path stored
- FFmpeg failure is handled gracefully (video marked as failed)
- Processing runs asynchronously (does not block caller)
- Video status transitions correctly through processing states
