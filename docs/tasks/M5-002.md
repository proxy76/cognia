# Task M5-002: Quiz CRUD API

**Milestone:** M5 Quiz & Progression
**Dependencies:** M5-001, M2-005

## Goal
Implement POST /quizzes for quiz creation, quiz submit/publish endpoints, and GET /quizzes/{id} that hides correct answers for quiz takers.

## Why This Task Exists
Creators need API endpoints to create and publish quizzes, and learners need to fetch quiz data without seeing the answers. The API must enforce role-based access and answer hiding to maintain quiz integrity.

## Source Docs
- Quiz domain models from M5-001
- Authentication/authorization from M2-005
- Content status state machine pattern from M4-001

## Non-Goals
- No quiz attempt or scoring logic — that's M5-003
- No quiz-taking UI — that's M5-007

## Files Expected
- Quiz CRUD controller/routes
- Quiz submit/publish endpoints
- Quiz request/response DTOs (with and without answers)
- Answer-hiding serialization logic
- Role-based authorization checks

## Acceptance Criteria
- [ ] POST /quizzes creates a quiz with questions and options
- [ ] POST /quizzes/{id}/submit transitions quiz to PENDING_REVIEW
- [ ] POST /quizzes/{id}/publish transitions quiz to PUBLISHED (licensed creators)
- [ ] GET /quizzes/{id} returns quiz without correct answer flags for non-owners
- [ ] GET /quizzes/{id} returns quiz with correct answer flags for the owner
- [ ] Only authenticated creators can create quizzes
- [ ] Validation enforces required fields and minimum question count

## Tests Required
- Create quiz with valid data
- Get quiz hides correct answers for non-owner
- Get quiz shows correct answers for owner
- Submit transitions quiz status correctly
- Publish restricted to licensed creators
- Role-based access enforced on all endpoints
- Validation rejects incomplete quiz data
