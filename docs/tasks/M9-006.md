# Task M9-006: Notification UI

**Milestone:** M9 Notifications & Analytics
**Dependencies:** M9-002, M9-003

## Goal
Build the notification bell with unread count badge, notification list screen, tap-to-navigate behavior, and mark-as-read functionality.

## Why This Task Exists
Users need a visual interface to view and interact with their notifications. The notification bell provides at-a-glance awareness of unread notifications, and the list screen allows browsing and acting on them.

## Source Docs
- M9-002 (Notification REST API)
- M9-003 (Notification WebSocket)
- UI/UX design specs

## Non-Goals
- No push notification permission handling (OS-level)
- No notification preferences/settings

## Files Expected
- `android/app/src/main/kotlin/.../notification/NotificationBell.kt`
- `android/app/src/main/kotlin/.../notification/NotificationListScreen.kt`
- `android/app/src/main/kotlin/.../notification/NotificationViewModel.kt`
- `android/app/src/main/kotlin/.../notification/NotificationItem.kt`

## Acceptance Criteria
- [ ] Notification bell icon shows unread count badge
- [ ] Notification list screen displays all notifications
- [ ] Tapping a notification navigates to the relevant screen
- [ ] Notifications can be marked as read individually and all at once
- [ ] Realtime updates via WebSocket reflect new notifications

## Tests Required
- ViewModel state tests for notification list loading
- ViewModel state tests for unread count updates
- ViewModel state tests for mark as read
- ViewModel state tests for realtime notification arrival
