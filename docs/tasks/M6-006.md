# Task M6-006: Search API

**Milestone:** M6 Feeds
**Dependencies:** M4-001, M5-001, M2-005, M3-001

## Goal

Implement the search API endpoint that queries across published videos, quizzes, creators, and categories using keyword matching. Include recent search history per user.

## Why This Task Exists

Search is essential for content discovery, confirmed as MVP-required. Users need to find specific content, creators, and topics beyond what the feeds surface.

## Source Docs

- `docs/06-api-contracts.md` (Search section)
- `docs/07-database-schema.md` (search_history table)
- `docs/01-mvp-scope.md` (Search section)

## Non-Goals

- No full-text search engine (Elasticsearch, etc.) — use SQL LIKE queries
- No search ranking algorithm beyond basic relevance
- No trending searches
- No search suggestions/autocomplete

## Files Expected

- `server/src/main/kotlin/com/cognia/app/search/SearchService.kt`
- `server/src/main/kotlin/com/cognia/app/search/SearchRepository.kt`
- `server/src/main/kotlin/com/cognia/app/search/SearchRoutes.kt`
- `shared/src/commonMain/kotlin/com/cognia/app/dto/search/SearchDtos.kt`
- Database migration for `search_history` table

## Acceptance Criteria

- [ ] GET `/search?q=...` returns results grouped by videos, quizzes, creators, categories
- [ ] Optional `type` filter returns only that result type with pagination
- [ ] Only published content appears in results
- [ ] Search query is case-insensitive
- [ ] GET `/search/recent` returns user's recent searches (most recent first, deduplicated)
- [ ] DELETE `/search/recent` clears history
- [ ] Empty query returns empty results (not an error)

## Tests Required

- Search returns matching videos by title/description
- Search returns matching creators by display name
- Search returns matching categories by name
- Unpublished content excluded from results
- Type filter works correctly
- Recent search stored on search
- Recent search retrieval and clearing
- Empty query handling
