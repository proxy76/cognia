# Task M8-004: Strike Logic with Cooldown and License Revocation

**Milestone:** M8 Moderation & Licensing
**Dependencies:** M8-002, M8-006

## Goal

Implement POST /moderation/strikes to issue strikes with the following consequences per strike:
1. **1-week cooldown**: Creator cannot upload or publish content for 7 days
2. **License revocation**: If the creator is a Licensed Creator, their license is revoked and they must restart the licensing process after cooldown ends

## Why This Task Exists

Strikes are the enforcement mechanism for content policy violations. Each strike has real consequences — a cooldown period and license revocation — making them a meaningful deterrent.

## Acceptance Criteria

- [ ] POST /moderation/strikes creates a strike with `cooldown_until = now + 7 days`

- [ ] Creator cannot upload or publish while in cooldown (check `cooldown_until`)
- [ ] Upload/publish attempts during cooldown return 403 with clear error message
- [ ] Strike count per user is tracked; 3 strikes is the max
- [ ] Strike history is queryable per user
- [ ] Only moderators can issue strikes
