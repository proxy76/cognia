# Task M9-005: Leaderboards API

**Milestone:** M9 Notifications & Analytics
**Dependencies:** M5-005, M7-002

## Goal
Implement GET /leaderboard/friends and GET /leaderboard/global returning ranked users by total points.

## Why This Task Exists
Leaderboards drive competition and engagement by letting users see how they rank against friends and the broader community. This gamification element encourages continued learning.

## Source Docs
- M5-005 (Points and leveling)
- M7-002 (Friend system for friend leaderboard)
- Leaderboard specs

## Non-Goals
- No weekly or monthly leaderboards
- No category-specific leaderboards

## Files Expected
- `server/src/main/kotlin/.../leaderboard/LeaderboardService.kt`
- `server/src/main/kotlin/.../leaderboard/LeaderboardController.kt`
- `server/src/main/kotlin/.../leaderboard/LeaderboardDtos.kt`

## Acceptance Criteria
- [ ] GET /leaderboard/global returns all users ranked by total points
- [ ] GET /leaderboard/friends returns only the user's friends ranked by total points
- [ ] Ranking includes user avatar, name, level, and points
- [ ] Ties are handled consistently (e.g., same rank for same points)
- [ ] Pagination supported

## Tests Required
- Global ranking returns users in correct order
- Friends ranking only includes the user's friends (and the user)
- Ties are handled consistently
- Empty friends list returns only the user
