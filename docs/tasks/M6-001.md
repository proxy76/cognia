# Task M6-001: For You feed generation logic

**Milestone:** M6 Feeds
**Dependencies:** M4-001, M3-003

## Goal
Build a feed service that generates a For You feed from the user's selected categories, with basic relevance sorting. The feed returns published content that matches the user's category preferences.

## Why This Task Exists
The For You feed is the primary content discovery surface for users. It needs to surface relevant content based on the categories users chose during onboarding, creating a personalized experience from day one.

## Source Docs
- M4-001 (Content domain and publishing)
- M3-003 (User category preferences from onboarding)
- Feed design specs

## Non-Goals
- No ML-based recommendations
- No behavior-based adaptation yet (that comes in M6-004)

## Files Expected
- `server/src/main/kotlin/.../feed/ForYouFeedService.kt`
- `server/src/main/kotlin/.../feed/FeedRepository.kt`
- `server/src/main/kotlin/.../feed/FeedModels.kt`

## Acceptance Criteria
- [ ] Feed service returns content matching the user's selected categories
- [ ] Only published content is included in the feed
- [ ] Content is sorted by basic relevance (e.g., recency within matched categories)
- [ ] Pagination support via cursor-based pagination
- [ ] Empty feed handled gracefully when no matching content exists

## Tests Required
- Feed returns content matching user categories
- Feed excludes unpublished content
- Pagination works correctly (cursor-based)
- Empty category set returns empty feed
- Content from non-selected categories is excluded
