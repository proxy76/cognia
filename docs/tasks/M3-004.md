# Task M3-004: Onboarding UI Flow

**Milestone:** M3 Onboarding
**Dependencies:** M1-006, M3-002, M3-003

## Goal
Build the onboarding UI screens: AI-driven questions, self-description input, category recommendation display with select/deselect, manual category add, and confirmation step.

## Why This Task Exists
New users need a guided onboarding experience that collects their interests and helps them select relevant content categories. This flow drives initial personalization and user engagement.

## Source Docs
- Onboarding flow design and wireframes
- M3-002 recommendation API contract
- M3-003 preference persistence API contract

## Non-Goals
- No profile settings editing of categories — that is a separate task
- No AI logic implementation (consumed via API from M3-002)

## Files Expected
- Onboarding screen composables/views (one per step)
- Onboarding ViewModel(s)
- Onboarding navigation graph/flow
- UI state models for each onboarding step
- Integration with recommendation and preference APIs

## Acceptance Criteria
- [ ] Self-description input screen captures free-text input
- [ ] Question screens collect user answers
- [ ] Recommendation screen displays suggested categories from API
- [ ] User can select/deselect recommended categories
- [ ] User can manually add categories not in recommendations
- [ ] Confirm screen shows final selections before saving
- [ ] Saving triggers PUT /onboarding/preferences
- [ ] Onboarding flow can be navigated forward and back
- [ ] Loading and error states are handled

## Tests Required
- ViewModel state tests for each onboarding step
- Self-description input updates state correctly
- Category selection/deselection toggles state
- Manual category add updates state
- Confirm step triggers preference save
- Error state handling (API failure)
- Navigation between steps
