# Task M5-005: Levels System

**Milestone:** M5 Quiz & Progression
**Dependencies:** M5-004

## Goal
Implement level calculation from total points with configurable thresholds. Detect level-up events and trigger notifications.

## Why This Task Exists
Levels provide visible progress milestones that motivate continued learning. Configurable thresholds allow tuning the progression curve, and level-up notifications create rewarding moments.

## Source Docs
- Points system from M5-004
- Gamification design documentation
- Level threshold configuration

## Non-Goals
- No badges — that's M5-006
- No leaderboard
- No UI for levels display (separate task)

## Files Expected
- Level definition/configuration (thresholds)
- Level calculation service
- Level-up detection logic
- Notification trigger for level-up events
- User level field (migration if not already present)

## Acceptance Criteria
- [ ] Level calculated from user's total points using configurable thresholds
- [ ] Level thresholds are configurable (e.g., Level 1: 0pts, Level 2: 100pts, Level 3: 300pts, etc.)
- [ ] Level-up detected when points cross a threshold
- [ ] Level-up triggers a notification event
- [ ] User's current level is queryable
- [ ] No level-down — levels only increase
- [ ] Level recalculated correctly after points update

## Tests Required
- Level calculated correctly at various point totals
- Level-up detected when crossing threshold
- No level-up when points increase within same level
- No level-down when system recalculates
- Configurable thresholds are respected
- Notification triggered on level-up
