# Task M3-002: Onboarding Recommendation API (Anthropic Claude Sonnet)

**Milestone:** M3 Onboarding
**Dependencies:** M3-001

## Goal

Implement POST /onboarding/recommend endpoint that accepts a self-description and onboarding answers, then calls the Anthropic API (Claude Sonnet) to generate category recommendations. Include a fallback to keyword matching if the API call fails.

## Why This Task Exists

The onboarding flow needs to suggest relevant categories to new users based on their interests and self-description. Using Claude Sonnet provides intelligent, context-aware recommendations.

- No fine-tuning or custom model training

- No streaming responses

## Acceptance Criteria

- [ ] POST /onboarding/recommend accepts self-description and answers
- [ ] Calls Anthropic API with a prompt containing user input and available categories
- [ ] Returns a ranked list of recommended categories from the available set
- [ ] Falls back to keyword matching if Anthropic API call fails or times out
- [ ] API key loaded from environment config (COGNIA_ANTHROPIC_API_KEY)
- [ ] Model configurable via COGNIA_ANTHROPIC_MODEL (default: claude-sonnet-4-20250514)
- [ ] Handles empty input gracefully (returns default/popular categories)

## Tests Required

- Recommendation returns categories for valid input (mock Anthropic API response)
- Fallback to keyword matching when API fails
- Handles empty self-description
- Handles empty answers
- Response format matches API contract
- API key missing → graceful fallback, not crash
