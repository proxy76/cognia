# Task M7-006: Shared post message type in chat

**Milestone:** M7 Social
**Dependencies:** M7-003, M4-001

## Goal
Support a SHARED_POST message type in chat that allows users to send a video or quiz reference. The shared post message includes content metadata for rendering a preview in the chat.

## Why This Task Exists
Sharing content through chat is a key social and viral loop. Users should be able to share interesting videos or quizzes with friends directly in a conversation.

## Source Docs
- M7-003 (Chat domain)
- M4-001 (Content domain)

## Non-Goals
- No new content types beyond video and quiz references
- No deep link handling on the client (that is a UI concern)

## Files Expected
- Updates to `ChatMessage.kt` for SHARED_POST type
- `server/src/main/kotlin/.../chat/SharedPostDto.kt`
- Updates to `ChatService.kt` for shared post handling
- Updates to `ChatController.kt` for shared post messages

## Acceptance Criteria
- [ ] SHARED_POST message type stores a reference to content (content ID)
- [ ] Sending a shared post validates the referenced content exists
- [ ] Retrieving a shared post message includes content metadata (title, thumbnail, type)
- [ ] Shared post references only published content

## Tests Required
- Shared post message stored with content reference
- Retrieval includes content metadata (title, thumbnail, type)
- Sharing unpublished content is rejected
- Sharing non-existent content is rejected
